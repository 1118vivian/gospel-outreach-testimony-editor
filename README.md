# 福音開展蒙恩見證稿編輯器

依據同層「福音開展蒙恩見證稿.docx」，參照學員蒙恩見證稿編輯器的操作方式與視覺樣式製作。

## 使用方式

以瀏覽器開啟 index.html 即可使用；請保留 app.js、styles.css 及 vendor 資料夾。

1. 選擇「隊員一週開展蒙恩見證稿（約300字）」或「全隊一週開展全隊蒙恩報導（約500字）」。
2. 填寫隊別、組別、姓名、週次、開始與結束日期，以及正文。
3. 檢查即時預覽並下載 DOCX 或 PDF，手機另提供「分享 Word」。

範本正文為整塊空白書寫區，因此保留單一正文欄位。字數計算不含空白。選擇全隊報導時，建議字數與檔名同步更新。

## 草稿與輸出

- 草稿只儲存在此瀏覽器，不會上傳，也不會與其他編輯器共用。清除瀏覽器資料會刪除草稿。
- 清空前會詢問確認，清空後回到預設的隊員見證類型。
- Word 採原生文字與表格，可直接修改內容；手機分享使用相同可編輯檔案。
- 預覽與 PDF 保留固定 A4 版面；Word 採明確行距與精簡間距，長文可自動換頁。
- 分享功能依瀏覽器與作業系統支援情況而定，不支援時改為下載。
- vendor 套件均在本機，不依賴外部 CDN。

## 部署

公開網址：https://1118vivian.github.io/gospel-outreach-testimony-editor/ 。推送 main 分支後會由 GitHub Actions 自動部署至 GitHub Pages。修改 app.js 或 styles.css 時，需同步更新 index.html 的版本號。
